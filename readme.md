#### 2. 주요 라이브러리 비교
|           | restTemplate                                                    | webclient                                                               |
|:----------|:----------------------------------------------------------------|:------------------------------------------------------------------------|
| 통신 방식     | - 동기 방식<br/>- HTTP 요청을 보내고 응답을 기다리는 동안 현재 스레드를 차단               | - 비동기 방식<br/>- HTTP 요청을 보내고 응답을 기다리는 동안 현재 스레드를 차단하지 않고 다른 작업을 수행할 수 있음 |
| 제공 버전     | Spring Framework의 일부로 제공되므로 Spring Boot 애플리케이션에서 기본적으로 사용할 수 있음 | Spring 5                                                                |
| 프로그래밍 스타일 | 간단한 API를 사용하여 HTTP 요청을 생성하고 응답을 처리                              | 함수형 프로그래밍 스타일로 HTTP 요청을 생성하고 응답을 처리                                     |                                                                       |
| 사용        | 간단한 동기 처리                                                       | 여러 개의 API를 기능 별로 호출할 때 유리                                               |                                                                         |
